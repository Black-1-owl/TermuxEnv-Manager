# 🔧 TermuxEnv Manager v2.4.1

Backup and restore manager for your Termux environment.



⚡ One-click backups. Safe, validated restores. Never lose your Termux setup again.

---

## ✨ Features

| Feature | Description | Why It's Cool |
| :--- | :--- | :--- |
| 📦 **Smart Backups** | Full, Home-only, Custom, or Quick backup modes. | Choose exactly what to save. |
| 🔄 **Package Integration** | FULL backup saves package list & can auto-reinstall. | Restores your tools, not just your files. |
| 🛡️ **Safety First** | Integrity verification, disk space checks, confirm prompts. | Prevents data loss and corrupted backups. |
| 📊 **Professional UI** | Color-coded menus, progress bars, ASCII art. | Makes CLI interaction pleasant and clear. |
| 🔍 **Advanced Tools** | View contents, extract single files, compare systems. | Full control over your backup data. |
| 🧹 **Auto-Cleanup** | Keeps last 15 backups, rotates old ones automatically. | Saves storage space. |
| 📱 **Termux Optimized** | Corrects Android storage paths & file structures. | It just works on your phone. |

---

## 🚀 Quick Start

### 1. Download & Run

Open Termux and run:

```bash
# Download the script
curl -L -o TermuxEnvManager.bash https://raw.githubusercontent.com/Black-1-owl/TermuxEnv-Manager/main/TermuxEnvManager.bash

# Make it executable
chmod +x termux-manager.sh

# Run it!
./termux-manager.sh
